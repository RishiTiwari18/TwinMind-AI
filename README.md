# TwinMind AI

TwinMind AI is an AI-powered personal knowledge and productivity assistant.

## Features

- Personal knowledge management
- Document-based AI chat
- Semantic search
- Goal and task management
- Personalized daily planning
- AI-assisted actions with user approval
- Progress analytics

## Technology Stack

- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Python
- FastAPI
- LLM API
- Embeddings and vector search
- Redis
- Docker

## Project Structure

- frontend/: React application
- backend/: Node.js and Express APIs
- ai-service/: Python AI service
- docs/: Project documentation

## Development Status

Project initialization and requirements planning.

## Security

Never commit API keys, passwords, database credentials, or environment files.
